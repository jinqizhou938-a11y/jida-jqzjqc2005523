# 灵感衣橱 — 产品需求文档 (PRD)

**版本：** v1.0 MVP + 社区基础版  
**更新日期：** 2026-05-23  
**文档状态：** 已定稿，进入开发

---

## 1. 产品概述

### 1.1 产品定位

「灵感衣橱」是一款帮助用户从抖音穿搭视频中快速提取搭配卡片、形成个人灵感库，并在社区中交流搭配心得的平台。

**核心价值主张：**
- 将「看了就忘」的短视频穿搭，转化为结构化、可保存、可检索的搭配卡片
- 通过轻社区形成穿搭灵感循环：发现 → 保存 → 分享 → 借鉴

### 1.2 目标用户

| 用户画像 | 特征 | 核心诉求 |
|---------|------|---------|
| 穿搭爱好者 | 18-35 岁，常刷抖音穿搭视频 | 快速记录灵感，避免遗忘 |
| 时尚博主粉丝 | 关注特定博主风格 | 拆解博主搭配，学习配色与单品 |
| 购物决策者 | 逛街/网购前需要参考 | 按场景、体型筛选合适搭配 |

### 1.3 产品目标（MVP）

| 目标 | 衡量指标 | 目标值 |
|-----|---------|--------|
| 链接解析成功率 | 有效抖音链接解析成功 | ≥ 90% |
| AI 识别准确率 | 用户主观满意度（风格/单品） | ≥ 75% |
| 卡片生成耗时 | 从提交链接到展示卡片 | ≤ 15 秒 |
| 社区互动 | 注册用户 7 日留存 | ≥ 30% |

## 3. 功能需求

### 3.1 链接解析与画面获取

#### FR-01 抖音链接智能解析

**用户故事：** 作为用户，我希望粘贴抖音分享口令或链接后系统自动识别，以便快速开始生成卡片。

**功能描述：**
- 支持输入：短链 `https://v.douyin.com/xxx`、长链 `https://www.douyin.com/video/xxx`、含「复制打开抖音」的完整口令
- 自动提取纯净 URL，验证合法性
- 非抖音链接时输入框标红，提示「仅支持抖音视频链接」

**验收标准：**
1. 粘贴含口令文本，自动截取 `https://v.douyin.com/xxx` 部分
2. 非抖音链接标红并提示错误
3. 支持短链与长链两种格式

**优先级：** P0

---

#### FR-02 自动获取视频前三帧

**用户故事：** 作为用户，我希望系统自动从视频中抽取关键画面，以便 AI 选择最佳穿搭展示帧。

**功能描述：**
- 后端解析链接获取无水印视频地址
- 使用 FFmpeg 抽取第 1、4、7 秒缩略图（假定前 10 秒为换装展示）
- 图片尺寸统一 640px 宽，高度按比例

**验收标准：**
1. 成功返回 3 张图片 URL
2. 视频时长 < 8 秒或抽帧失败时，降级使用视频封面图
3. 图片上传至 Supabase Storage 并返回公开 URL

**优先级：** P0

---

#### FR-03 AI 择优选择最佳穿搭帧

**用户故事：** 作为用户，我希望 AI 自动挑选穿搭展示最完整的画面，以便生成高质量卡片。

**功能描述：**
- 3 张图片并发调用 GLM-4V
- Prompt 要求输出：主要人物衣物完整度得分（0-10）、是否全身搭配可见
- 选择得分最高的图片用于生成卡片

**验收标准：**
1. 前端显示「AI 正在挑选最佳画面...」进度
2. 所有得分 < 5 时提示「该视频穿搭不明显，换一个试试吧」
3. 择优耗时 < 5 秒

**优先级：** P0

---

### 3.2 AI 识别与卡片生成

#### FR-04 结构化识别衣物信息

**用户故事：** 作为用户，我希望 AI 自动识别穿搭的风格、单品、配色等信息，以便快速了解搭配要点。

**功能描述：**
- 将最佳图片发送 GLM-4V，返回固定 JSON 格式
- 字段：style、items、color_palette、scene、body_type_advice
- 识别不出时使用「未知/通用建议」兜底

**JSON 输出格式：**
```json
{
  "style": "韩系清冷/Y2K/日系文艺/其他",
  "items": [{"type": "上衣", "color": "白色", "detail": "印花T恤"}],
  "color_palette": [{"name": "奶油白", "hex": "#FFF5E6"}],
  "scene": "通勤/约会/逛街/运动/度假",
  "body_type_advice": "梨形身材：这款A字裙很友好"
}
```

**验收标准：**
1. 所有字段必填，有兜底值
2. 识别时间 < 3 秒

**优先级：** P0

---

#### FR-05 搭配卡片渲染与交互

**用户故事：** 作为用户，我希望看到美观、信息丰富的搭配卡片，并能保存或添加私人笔记。

**卡片组成：**
- 穿搭图（左上圆角）
- 风格胶囊标签
- 单品拆解行
- 配色色块
- 场景图标
- AI 小建议

**交互：**
1. 鼠标悬停图片 scale 1.05/05，标签栏平滑滑入
2. 右下角 ⭐ 按钮保存到灵感墙（未登录跳转登录）
3. 点击卡片主体弹出模态框，可添加/编辑私人笔记

**优先级：** P0

---

### 3.3 个人灵感墙

#### FR-06 卡片管理

**用户故事：** 作为用户，我希望管理已保存的搭配卡片，包括删除、置顶和编辑笔记。

**功能描述：**
- 已保存卡片按时间倒序瀑布流展示
- 置顶卡片始终排在顶部
- 支持删除、置顶、编辑笔记

**验收标准：**
1. 删除需二次确认「确认移出灵感墙？」
2. 置顶卡片排在列表顶部

**优先级：** P0

---

#### FR-07 筛选与搜索

**用户故事：** 作为用户，我希望按场景或关键词快速找到想要的搭配卡片。

**功能描述：**
- 顶部筛选：全部 / 通勤 / 约会 / 逛街 / 度假
- 搜索框支持关键词（衣物类型或颜色）
- 模糊匹配，不区分大小写

**验收标准：**
1. 点击筛选实时刷新列表
2. 搜索支持模糊匹配

**优先级：** P1

---

#### FR-08 空状态与导出

**用户故事：** 作为新用户，我希望在没有卡片时看到引导，知道如何开始使用。

**功能描述：**
- 无卡片时显示插画 + 引导文案
- 暂不做长图导出，用浏览器打印功能代替

**优先级：** P2

---

### 3.4 社区功能

#### FR-09 发布到社区

**用户故事：** 作为用户，我希望将喜欢的搭配卡片分享到社区，供他人借鉴。

**功能描述：**
- 灵感墙卡片点击「🌐 发布」
- 选择公开 / 仅好友可见（MVP 仅实现公开）
- 自动带上原卡片标签，可手动添加话题（如 #夏日穿搭）
- 社区广场按发布时间倒序展示

**验收标准：**
1. 发布时自动携带标签，可添加话题
2. 社区广场按时间倒序展示公开卡片

**优先级：** P0

---

#### FR-10 社区互动

**用户故事：** 作为用户，我希望对社区卡片点赞、评论，与其他用户交流穿搭心得。

**功能描述：**
- 点赞：实时更新计数，可取消
- 评论：支持文字 + 表情，频率限制 5 条/分钟
- 用户主页显示个人发布的卡片列表

**验收标准：**
1. 点赞实时更新，可取消
2. 评论防刷：5 条/分钟

**优先级：** P0

---

#### FR-11 用户关注与动态流

**用户故事：** 作为用户，我希望关注喜欢的穿搭达人，在动态流中看到他们的最新分享。

**功能描述：**
- 关注/取消关注其他用户
- 「关注」Tab 展示被关注者最新发布的卡片
- 按发布时间倒序，支持分页加载

**验收标准：**
1. 关注按钮状态切换
2. 动态流按时间倒序分页

**优先级：** P1

---

#### FR-12 内容审核

**用户故事：** 作为平台，我们需要对用户举报的内容进行审核，维护社区健康。

**功能描述：**
- 任何用户可点击「举报」，填写原因
- 管理员后台查看被举报卡片
- 支持隐藏/恢复（`is_hidden` 字段）

**验收标准：**
1. 用户可举报并填写原因
2. 管理员可查看未审核列表并操作

**优先级：** P1

---

### 3.5 用户体系

#### FR-13 注册登录

**用户故事：** 作为用户，我希望通过手机号或邮箱快速注册登录，使用完整功能。

**功能描述：**
- Supabase Auth：手机验证码或邮箱密码
- 登录状态持久化（localStorage refresh token）
- 未登录只能浏览社区

**验收标准：**
1. 登录状态持久化
2. 未登录限制保存/发布/点赞

**优先级：** P0

## 6. 核心用户流程

### 6.1 生成卡片流程

```
输入抖音链接 → 解析验证 → 抽帧(3张) → AI择优 → AI识别 → 渲染卡片 → 保存/发布
     ↓              ↓           ↓          ↓         ↓
   错误提示      封面降级     进度展示    低分提示   结构化JSON
```

### 6.2 社区互动流程

```
浏览广场 → 点击卡片 → 查看详情 → 点赞/评论
                ↓
           关注作者 → 关注Tab看动态
```

## 7. UI/UX 设计原则

- **轻量感：** 白色/奶油色主调，圆角卡片，适度留白
- **时尚调性：** 胶囊标签、配色色块、柔和阴影
- **即时反馈：** 加载态、成功/错误 Toast、骨架屏
- **移动优先：** 瀑布流布局，触控友好按钮尺寸

## 9. 风险与应对

| 风险 | 影响 | 应对 |
|-----|------|------|
| 抖音链接解析失效 | 核心功能不可用 | yt-dlp 定期更新；封面降级 |

| 社区内容违规 | 平台风险 | 举报 + 人工审核 |
